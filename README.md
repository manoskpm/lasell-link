# LaSell Link (라셀링크)

유튜브 · 인스타 · 틱톡 라이브셀러를 위한 판매 · 주문 · 정산 · 택배 관리 플랫폼

## 주요 기능

- **소비자 화면** (모바일 우선): 상품 목록/상세(사이즈·색상 옵션), 장바구니, 주문, 주문내역, 배송조회
- **관리자 화면** (PC 우선): 상품·재고 관리, 주문·정산(일자별/기간별), 회원 관리, 택배 접수
- **회원 시스템**: 회원가입 시 배송지 저장, 관리자/일반회원 권한 분리 (첫 가입자가 관리자)
- **택배 연동**: 택배사 대량접수 엑셀 양식을 등록하면 칸을 자동 인식 → 주문 선택 후 그 양식대로 엑셀 다운로드, 운송장번호 엑셀을 다시 올리면 자동 입력 + 발송완료 처리, 배송조회 링크 자동 생성
- **엑셀 다운로드**: 주문내역(기간별), 회원목록
- **상점 설정**: 상호명, 로고, 카카오채널/오픈채팅 문의 버튼, 입금계좌, 택배사 정보

## 기술 스택

- Next.js (App Router) + TypeScript + Tailwind CSS
- Prisma 7 + SQLite (better-sqlite3 드라이버 어댑터)
- ExcelJS (택배 양식 처리, 엑셀 다운로드)

## 시작하기

```bash
npm install
npx prisma migrate deploy
npm run dev
```

`http://localhost:3000` 접속 후 **첫 번째로 회원가입하는 계정이 자동으로 관리자 계정**이 됩니다.

## 환경 변수

`.env` 파일에 다음을 설정하세요 (기본값은 `prisma7.config.ts` 참고):

```
DATABASE_URL="file:./dev.db"
```
