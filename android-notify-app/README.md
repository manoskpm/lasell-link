# 라스켓 입금 알림 (안드로이드)

은행 앱 알림 중 셀러가 고른 것만 읽어서 라스켓 서버로 보내는 아주 작은 앱.
카톡·문자 등 다른 알림은 앱이 아예 쳐다보지 않는다 (NotifyListenerService.kt 참고).

## 빌드 방법 (깃허브 자동 빌드, 2026-10-02부터)

- `android-notify-app/` 이 바뀌어 올라오면 깃허브가 자동으로 APK를 만든다 (`.github/workflows/android-notify-app.yml`).
  저장소 > Actions > android-notify-app > 맨 위 실행 > Artifacts 에서 받는다. 빌드 정보(커밋·시각·SHA-256)는 같이 들어 있는 BUILD_INFO.txt.
- 디버그 APK: 항상 만들어짐. 시험용. 서명이 빌드마다 달라질 수 있어 업데이트하려면 지우고 다시 깔아야 할 수 있음.
- 정식(release) APK: 깃허브 비밀값 4개가 있을 때만 만들어짐 — `LASKET_KEYSTORE_BASE64`(키 파일을 base64로), `LASKET_KEYSTORE_PASSWORD`, `LASKET_KEY_ALIAS`, `LASKET_KEY_PASSWORD`. 키·비밀번호는 저장소에 절대 넣지 않는다. 키를 잃으면 이미 깔린 앱을 업데이트할 수 없으니 원본을 따로 보관.
- 셀러 폰에는 플레이스토어가 아니라 파일로 설치 ("출처를 알 수 없는 앱 설치" 허용 필요). 첫 시험은 제한된 드라이브 링크로 전달, 작동 확인 뒤 라스켓 셀러 설정 화면의 "알림앱 받기"로 바꿀 예정 (GPT 사전검토 25번 합의).
- 작동 단계(2026-10-02): ② 빌드됨 확인. ③ 설치 ④ 실제 알림 수신은 확인 안 됨.

## 셀러가 할 일 (앱 안에서)

1. 라스켓 관리자 화면 > 설정에서 발급받은 **주소**와 **연동키**를 붙여넣고 저장
2. 쓰는 은행 앱 체크 (처음 켤 때 폰에 깔린 은행 앱은 미리 체크돼 있음)
3. "알림 접근 허용하러 가기" → 라스켓 입금 알림 앱을 켜기
   - 안드로이드 13 이상에서 버튼이 회색이면: 앱 화면의 "앱 정보 열기" → ⋮ → "제한된 설정 허용" 후 다시 (기종별 메뉴 이름은 실제 폰으로 확인 필요)
4. "배터리 최적화 제외하러 가기" (특히 삼성 폰 — 안 하면 화면 꺼졌을 때 알림이 안 옴)

## 구조

- `MainActivity.kt` — 설정 화면. 주소/연동키/은행 앱 선택을 SharedPreferences에 저장
- `NotifyListenerService.kt` — 알림이 뜰 때마다 실행됨. 선택된 은행 앱 패키지명이 아니면 즉시 무시.
  맞으면 제목+본문을 서버로 POST (`Authorization: Bearer <연동키>`)
